# Elementos de entorno

Origen: ELEMENTOS ENTORNO.glb, aportado por el usuario; copia sin modificar. Se utilizan sus quince piezas independientes: dos montañas, tres módulos de estacionamiento/acceso, tres arbustos, banco, silla, farola, tacho, buggy, camión y van.

Se mantienen sus medidas originales. Las montañas reciben una escala uniforme para el horizonte. Los módulos de estacionamiento se ubican junto al transporte y la logística; los coches tienen obstáculos de navegación y los suelos elevan el apoyo del personaje. El buggy queda junto al taller. Los bancos principales conservan las posiciones del control de sentarse. Las piezas se adaptan al sombreado ilustrado desde EnvironmentProps.tsx.

El archivo no contiene animaciones. Estos vehículos son ambientación estática; ROBER conserva su control remoto independiente. El origen es un archivo del usuario, no un recurso NASA ni una licencia pública inferida.
