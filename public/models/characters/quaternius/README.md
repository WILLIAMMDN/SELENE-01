# Exploradora terrestre — Quaternius

Personaje fuente: Casual2_Female, Ultimate Animated Character Pack de Quaternius.
Página primaria y licencia CC0: https://quaternius.com/packs/ultimatedanimatedcharacter.html
Copia pública del GLB utilizada: https://git.deuchnord.fr/non0w/jrpg_draft/raw/branch/develop/jrpg/models/chars/Casual2_Female.glb
El archivo oficial enlazado en Google Drive devolvía Quota exceeded durante la descarga. Se obtuvo esta copia pública del personaje, sin modificar ni incluir código del repositorio espejo.

Archivo: explorer.glb, 822 932 bytes. Siete clips de origen: Idle, Walk, Run, PickUp, SitDown, Punch y RecieveHit (nombre original). Materiales: Shirt, Skin, Pants, Belt, Face, Hair. Se normaliza a 1,80 m, se suavizan las normales conservando atributos de rig y se aplica ropa crema/coral, cabello grafito, tres tonos y contornos deformables. El modelo no se presenta como el personaje de las imágenes de referencia ni como una creación original del proyecto.

Es el único personaje terrestre activo; Ellis fue retirado. La integración conecta marcha, carrera, interacción y sentarse (levantarse invierte SitDown). Los siete clips permanecen en el GLB; no todos tienen un botón en la interfaz. El salto usa la física del juego y no tiene un clip propio. La revisión visual de las transiciones queda a cargo del equipo.
